# Cody

## 1. Objetivo do Projeto

O CODY é uma plataforma interna de orquestração de comunicações (iPaaS) projetada para substituir a solução legada "EVA". O sistema centraliza a governança de disparos corporativos (E-mail, MS Teams, WhatsApp) permitindo que times de RH e Comunicação criem jornadas automatizadas e broadcasts pontuais.
O objetivo estratégico é internalizar a orquestração de mensagens para reduzir custos operacionais, aumentar a governança de dados e preparar a arquitetura para futuras integrações com Inteligência Artificial. O diferencial do sistema reside em sua capacidade híbrida de atender tanto o RH (com interfaces intuitivas) quanto a TI (com APIs robustas), utilizando uma arquitetura assíncrona de alta performance. Além disso, a arquitetura do CODY foi desenhada visando modularidade e escalabilidade, pavimentando o caminho para uma futura evolução do produto para um modelo SaaS comercializável.
